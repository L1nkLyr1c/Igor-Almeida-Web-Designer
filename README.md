# Igor-Almeida-Web-Designer

Site pessoal de Igor Almeida, web designer. Página única em HTML/CSS/JS, sem build.

## Publicação
O Cloudflare Pages publica automaticamente a branch `main`. Pull requests geram um link de prévia.

## Formulário
Usa o Web3Forms (`WEB3FORMS_KEY` no `index.html`). A chave é pública por design: só permite enviar mensagens para o e-mail cadastrado.
